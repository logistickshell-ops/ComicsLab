# КомиксЛаб — конструктор комиксов

Лёгкий веб-сервис: загружаешь **1–4 картинки** → делаешь **раскадровку** перетаскиванием → добавляешь **облачка и подписи** → скачиваешь готовый комикс в **PNG**.

Всё работает полностью в браузере (Canvas API), сервер не нужен — картинки никуда не отправляются.

## Возможности

- Загрузка картинок: кнопка, drag-and-drop на лист, вставка из буфера (Ctrl+V)
- Раскадровка: порядок кадров меняется перетаскиванием миниатюр или стрелками
- Раскладки листа под 1/2/3/4 кадра (сетка 2×2, полосы, «герой + кадры» и др.)
- Кадрирование фото: тяни картинку внутри кадра мышкой/пальцем + ползунок масштаба
- Фильтры кадров: Комикс, Яркий, Ч/Б нуар, Ретро, Холодный
- Надписи 4 типов: **Реплика** (овал с хвостом), **Мысль** (облако), **Подпись** (прямоугольник), **Крик** (звезда)
  - перетаскивание по кадру, изменение ширины за уголок
  - редактирование текста двойным кликом прямо на листе
  - 3 шрифта с кириллицей, размер, цвета фона/текста, направление хвоста
- Форматы листа: 4:5, 1:1, 9:16 (сторис), 16:9, 3:4; заголовок; цвет фона
- Экспорт PNG 1080 / 1600 / 2048 px, кнопка «Поделиться» (Web Share API)
- Автосохранение проекта в localStorage
- Демо-история про суперкота из коробки

## Запуск локально

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/ (один HTML-файл, всё заинлайнено)
npm run preview  # посмотреть собранную версию
```

## Деплой на Render (Static Site)

1. Залей репозиторий на GitHub.
2. Render → **New → Static Site** → подключи репозиторий.
3. Настройки:
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist`
4. Deploy. Готово — сайт будет на `https://<имя>.onrender.com`.

> Сборка использует `vite-plugin-singlefile`: весь JS/CSS и демо-картинки инлайнятся в один `dist/index.html`. Поэтому подойдёт вообще любой статический хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

## Telegram Mini App

Приложение уже готово к работе внутри Telegram:

- подключён `telegram-web-app.js`, вызывается `ready()` + `expand()`
- главная кнопка Telegram (**MainButton**) «Скачать комикс PNG» появляется автоматически
- хаптика на действиях, шаринг через системное меню, подсказка «зажми картинку для сохранения»

Подключение бота:

1. Создай бота у [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Там же: `/newapp` → выбери бота → укажи URL задеплоенного сайта (Render), название и короткое имя (short name).
3. Ссылка на мини-апп будет вида `https://t.me/<bot>/<short_name>`.
4. По желанию: `/setmenubutton` у BotFather — кнопка меню бота со ссылкой на тот же URL.

Никакого бэкенда для мини-аппа не требуется: сборка комикса и скачивание происходят на устройстве пользователя.
